# Control catalog conformance matrix

This is an implementation evidence index, not a roadmap or progress tracker. `docs/MILESTONES.md` remains the sole owner of milestone status. Rows are limited to controls currently promoted by the registry; the drift test requires every future palette control to add one row and named test evidence.

The registry remains authoritative for every behavioral column. “Common harness” means `tests/control-definition-conformance.test.ts`, which inserts, validates, serializes, reopens, hit-tests, names, thumbnails, exports, and redraws every palette definition. The visual fixture column refers to the packaged `registryControl` matrix state.
